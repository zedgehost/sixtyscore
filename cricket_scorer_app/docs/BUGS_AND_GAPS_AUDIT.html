GAP-13: DLS Target Result Inversion Bug 🔴 Critical (P0)
📁 lib/scoring.dart:766-777

Root Cause: In `computeResult()`, the match winner comparison directly evaluates `if (i2.totalRuns > i1.totalRuns)` and `else if (i1.totalRuns > i2.totalRuns)`, completely omitting `i2.target`. In any match where Duckworth-Lewis-Stern reduces Team 2's target below Team 1's score (e.g. Team 1 made 160 in 20 overs, rain reduces Team 2's target to 95 in 10 overs), if Team 2 scores 95 to win, `95 > 160` is FALSE, and `160 > 95` is TRUE. The app erroneously declares Team 1 the winner by 65 runs!

⚠️ Technical & User Impact: Severe match corruption. Winning teams are declared losers, tournament points are awarded to the wrong team, and scorecards record false results. 
// lib/scoring.dart:766-777
if (i2.totalRuns > i1.totalRuns) {
  final wktsLeft = maxWkts - i2.wickets;
  final ballsUsed = i2.legalBalls;
  final ballsLeft = i2.oversLimit * i2.ballsPerOver - ballsUsed;
  text = '${teamName(i2.battingTeamId)} won by $wktsLeft wicket${wktsLeft == 1 ? '' : 's'}...';
} else if (i1.totalRuns > i2.totalRuns) {
  final margin = i1.totalRuns - i2.totalRuns;
  text = '${teamName(i1.battingTeamId)} won by $margin run${margin == 1 ? '' : 's'}';
}
🛠️ Remediation Strategy: Check `if (i2.target > 0)`: If `i2.totalRuns >= i2.target`, Team 2 wins by wickets. If `i2.totalRuns < i2.target - 1`, Team 1 wins by `(i2.target - 1) - i2.totalRuns` runs (DLS method). If equal, it is a tie.

GAP-16: ICC DLS Standard Regulations Violation in NRR Calculation 🔴 Critical (P0)
📁 lib/scoring.dart:1300-1304, lib/nrr_calculator.dart

Root Cause: In `computePointsTable`, `account(InningsState inn)` unconditionally adds Team 1's actual total runs and full 20-over balls (`batRow.runsFor += inn.totalRuns; batRow.ballsFor += balls;`). ICC Clause 16.10.2 stipulates: when DLS is applied, Team 1 must be credited with 1 run less than Team 2's target score off the number of overs allocated to Team 2.

⚠️ Technical & User Impact: Massive mathematical distortion in league NRR standings. Teams in rain-affected matches suffer severely unfair NRR penalties or artificial boosts.

Root Cause: ICC rules require a minimum number of overs (typically 5 for T20, 20 for ODI) to constitute an official match under DLS. The UI does not display a minimum over threshold warning.

⚠️ Technical & User Impact: Scorers could prematurely apply DLS before legal minimum overs are completed. 
// lib/screens/scoring_screen.dart:917-919

🛠️ Remediation Strategy: Display an advisory warning if fewer than 5 overs (or tournament minimum) have been bowled.
